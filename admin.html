Ranger les contrats signés existants

Sélectionnez les fichiers du dossier « Contrats signés - import appli ». Chaque fichier contient entre crochets l'identifiant de son partenaire, par exemple « Picto [1a2b3c4d].pdf » : il est rangé automatiquement dans la bonne fiche. Un fichier déjà rangé n'est pas ajouté une deuxième fois.

    La date d'effet se modifie directement dans le tableau. Durée, échéance et reconduction se règlent dans le bloc « Contrat de partenariat » de chaque fiche.
